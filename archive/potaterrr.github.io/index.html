# How it works

Three steps from "we do this by hand" to "it runs itself."

$ step 1

Fit call

A 60-minute call. We map the process, count the hours it eats, and decide together whether automation is worth it. If it isn't, I say so.

$ step 2

Build the sprint

Fixed scope, 2–3 weeks. You see a working automation in your own stack early — not a proposal deck. Weekly check-ins, no surprises.

$ step 3

Handoff

Documentation, a walkthrough, and a live automation running without me. Need ongoing tuning? The partner retainer covers it.
