Use cases

Dormant CRM

Reopen old leads with a specific note that references the original conversation, not a blast.

Quote follow-up

Follow up on estimates that never got a yes or a no, before they go cold.

Event and webinar lists

Turn a tired attendee list into real conversations with a human approving every send.

Trial expiry

Check in before a trial quietly lapses, with the original context already in the draft.

The loop

  • Pull the dormant leads and their original context
  • An LLM drafts a short, specific check-in — never a generic blast
  • The email is filed as a Gmail draft for review
  • A booking link is added so a reply turns into a call
  • CRM tracks each lead through the review lifecycle

Guardrails

  • AI drafts, a human approves — nothing sends itself
  • Anti-hallucination rules: the only link in any email is mine
  • Original context is passed to the model so the note is relevant
  • Every action is visible in the CRM, not buried in a mailbox
