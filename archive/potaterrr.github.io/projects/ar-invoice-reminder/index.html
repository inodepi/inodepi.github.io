Use cases

Net-30 and net-60 clients

Sweep the tracker daily and match the reminder tone to how late the invoice actually is.

Retainer and milestone billing

Chase the invoice without sounding like you are chasing the relationship.

Disputed invoices

Stop the sequence when a client replies with a question and escalate with the full context.

Owner approval

Every reminder waits as a Gmail draft; nobody sends a collections email by accident.

How it works

  • Schedule trigger fires at 09:00 and reads the invoice sheet
  • A Code node drops paid and void rows, parses amounts and dates, computes days past due and picks a tone
  • Gemini drafts against a structured output parser
  • A second Code node enforces the signature and falls back to a template if the model returns nothing usable
  • The draft lands in Gmail — nobody sends an email automatically
  • The follow-up date is written back to the sheet

Guardrails

  • Tone is computed in code, not guessed: friendly under 14 days, firm to 30, solution-oriented after
  • The signature is rebuilt in code, so the model can't rewrite it
  • A 7-day cooldown per invoice stops duplicate chasing
  • Strict JSON, no placeholders, a human presses send
