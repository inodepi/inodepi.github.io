Use cases

New-hire onboarding

Baseline a new SDR in week one and track opening, discovery, objection handling, next step and compliance as they improve.

Weekly rep coaching

Give every rep a scorecard with exact quotes instead of a manager’s memory of one call.

Objection library

Find the objections that get dismissed and turn the best responses into a shared playbook.

Next-step discipline

Catch calls that end with “I’ll follow up sometime” and coach the date-and-owner habit.

AI SDR QA

Score the AI SDR with the same rubric as the humans, so the comparison is honest.

Compliance review

Check recording disclosure, pricing claims and do-not-call handling across the team.

How it works

  • Retell posts the finished call to a webhook; a form accepts a pasted transcript for testing
  • A Code node normalizes the payload and refuses to score a call without a usable transcript
  • Gemini scores opening, discovery, objection handling, next step and compliance through a structured output parser
  • A second Code node clamps the scores, recomputes the weighted overall, verifies each quote against the transcript, and redacts emails and phone numbers
  • Clean calls go to the Sales Call QA data table; risky or low-confidence calls also become a Gmail draft for a manager
  • Every Monday, a digest aggregates the last week per rep and files one coaching draft

Guardrails

  • Every score must cite an exact quote; unverifiable evidence lowers confidence and forces review
  • The overall is computed in code, not guessed by the model
  • Any red flag, compliance below 3, or confidence below 0.75 always needs a human
  • No objection? Objection handling scores 3 with “no objection in transcript” — the rep is not punished for an easy call
  • Nothing is sent automatically — Gmail drafts wait for a manager
  • Transcripts are truncated, and emails and phone numbers are redacted in the stored evidence

Honest limits

The demo runs on synthetic calls. The Retell webhook is wired, but live telephony needs a real Retell agent and a public n8n URL. On the demo instance the Gmail credential was expired during the build, so draft creation is skipped while the scorecard still saves — reconnect it to see the manager drafts.
