Overview

rss-news feeds the AI Tech & Automation Hub page without a human in the loop: Python fetches the week's RSS links on a Sunday cron, filters and dedupes them, and hands a clean digest to Make.com. Gemini writes the post, Imagen generates the graphic, and Facebook Pages publishes it — the only manual step is reading it.

Pipeline

  • Python fetches Hacker News, Phoronix, The Verge and other RSS feeds
  • Keyword filtering plus seen_articles.json dedupe so nothing posts twice
  • The digest is POSTed to a Make.com webhook
  • Runs on the Make.com free tier — 1,000 operations a month covers a weekly run many times over; the trade-off is the 15-minute webhook polling interval, which doesn't matter on a Sunday cron
  • Gemini drafts the post, Imagen generates the graphic, Facebook Pages publishes it
  • GitHub Actions runs the whole thing every Sunday at 06:00 PHT
