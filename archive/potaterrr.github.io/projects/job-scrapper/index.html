job-scrapper

A Python scraper that watches OnlineJobs.ph and posts one Discord embed per job.

Overview

Job boards reward the first reply. A scraper that checks every ten minutes gets blocked; one that checks once a day is too late.

job-scrapper searches OnlineJobs.ph on a four-hour cadence, keeps the freshest listing per keyword, and posts one rich Discord embed per job so the channel stays readable.

Use cases

Job seekers

Get fresh listings in Discord before the board fills with applicants.

Recruiters

Watch niche categories and keywords without refreshing the site all day.

Niche boards

Swap the source and keep the same summarize-and-post pipeline.

Alert channels

One embed per job, deduped, every four hours, so the channel stays readable.

How it works

  • Searches each category's keywords with a randomized 5–12 second pause between requests
  • Parses every result card and sorts by the exact posting timestamp
  • Keeps the top listing per keyword, dedupes across keywords, caps per category
  • Visits each listing for the full description and splits out the "How to Apply" section
  • Summarizes each job with Gemini (falling back to raw fields if the API fails)
  • Dedupes by URL through seen_jobs.json so repeat runs stay quiet

Pipeline history

  • v1 · Make.com (retired): GitHub Actions POSTed each job as JSON to a Make webhook; the scenario routed it through Gemini and delivered to Telegram
  • v2 · GitHub Actions (current): scrape, Gemini summary and Discord delivery all run in one workflow, deduped by seen_jobs.json
  • v3 · n8n (on hold): GitHub Actions posts a batch to an n8n webhook; n8n owns the job_scrapper_seen dedupe table, the Gemini summary and the Discord post. Saved and waiting on the new n8n version

Notes

It started as a Make.com webhook pipeline with Telegram delivery, then moved fully into GitHub Actions: scrape, summarize, post — no second platform in the loop.

The next step is an n8n workflow: GitHub Actions keeps the cron and the polite scraping, then posts a batch to an n8n webhook that owns dedupe state, the Gemini summary and the Discord delivery. The workflow is written and on hold until the new n8n version lands.
